# 가족 여행 (2610)

- `trip-app/` 여행 플래너(PWA). 일정, 항공편, 숙소 요약, 내 정보(비공개 금고). 자세한 내용은 `trip-app/README.md`.
- `archive/` 지난 페이지 보관(여행지 투표, 비용 비교 아카이브). 앱과 코드를 공유하지 않는다.
- `index.html` 데이터 없는 리다이렉트(예전 주소 호환). 쿼리와 해시를 그대로 `trip-app/` 으로 넘긴다.
- `scripts/check-secrets.sh` 커밋 전 비밀값 검사.

이 저장소는 공개다. 코드와 껍데기만 두고, 여행 데이터는 두지 않는다.
- 여행 키는 초대 링크(`#k=...`)로만 전달한다.
- 여행 데이터(항공, 숙소, 일정)는 Firestore, 예약번호나 주소 같은 비밀은 별도 Worker 에 둔다.

테스트: 저장소 루트에서 `node --test "trip-app/test/*.test.mjs"` (Node 22, 외부 라이브러리 없음).
